# RecoverAI

Python + React project initialization.

## Project structure

- `/frontend`: React app scaffolded with Vite
- `/backend`: Minimal Python backend service

## Frontend (React)

```bash
cd /home/runner/work/RecoverAI/RecoverAI/frontend
npm install
npm run dev
```

## Backend (Python)

```bash
cd /home/runner/work/RecoverAI/RecoverAI/backend
python app.py
```

Health endpoint:

```bash
curl http://127.0.0.1:8000/health
```
